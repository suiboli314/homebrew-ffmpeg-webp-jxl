# Suiboli314 Ffmpeg-webp-jxl

## How do I install these formulae?

`brew install suiboli314/ffmpeg-webp-jxl/<formula>`

Or `brew tap suiboli314/ffmpeg-webp-jxl` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "suiboli314/ffmpeg-webp-jxl"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
